## 1. מה המערכת עושה?

המערכת מרכזת במקום אחד את כל הפניות שמגיעות לבר: מוואטסאפ, מאינסטגרם, בטלפון, מהאתר ומלקוחות שמגיעים פיזית. הצוות יכול לראות את הפניות, לסנן אותן ולטפל בהן ישירות מהטלפון, גם באמצע משמרת.

**סוגי הפניות שהמערכת מטפלת בהן:**
📅 הזמנת מקום · 😤 תלונה · 🎉 אירוע פרטי · 🔎 אבדות ומציאות · 💖 משוב · ❓ שאלה כללית · 🧑‍🍳 מועמדות לעבודה

## 2. איך המערכת עובדת?

| מסך | מה רואים שם |
|---|---|
| 🏠 **דאשבורד** | מדדים מרכזיים: פניות פתוחות, פניות חדשות היום, זמן תגובה ממוצע, שביעות רצון, הזמנות להערב. גרפים של פניות לפי יום, לפי סוג ולפי ערוץ. רשימה של פניות דחופות |
| 📋 **פניות** | רשימת כל הפניות, עם חיפוש ופילטרים לפי סוג, סטטוס, עדיפות וערוץ |
| 🔍 **פרטי פנייה** | פרטי הלקוח וכפתורי חיוג ווואטסאפ. אפשר לשנות סטטוס, לשייך את הפנייה לנציג, להוסיף הערות ולשלוח תשובות מוכנות מראש |
| 📅 **הערב** | כל ההזמנות של היום לפי שעה, ומספר הסועדים הצפוי |

**מחזור החיים של פנייה:**
`חדש 🔵` → `בטיפול 🟡` → `טופל 🟢` → `סגור ⚪`

**שמירת שינויים:** כל שינוי נשמר בדפדפן שלך (localStorage), ולכן נשאר גם אחרי רענון של הדף. כפתור **"איפוס דמו"** מחזיר את כל הנתונים למצב ההתחלתי.

## 4. הוראות הפעלה

### אפשרות א': פתיחה מקומית (הכי פשוט)
1. מורידים את הפרויקט: **Code → Download ZIP** ב-GitHub, או משכפלים אותו:
   ```bash
   git clone https://github.com/yigaldf/aido-customer-services.git
   ```
2. פותחים את הקובץ `index.html` בדפדפן בלחיצה כפולה.
3. זהו, המערכת עובדת. 🎉

### אפשרות ב': שרת מקומי (אם הגרפים לא נטענים)
```bash
cd aido-customer-services
```
```bash
python3 -m http.server 8000
```
אחר כך פותחים בדפדפן את הכתובת http://localhost:8000

### אפשרות ג': פרסום באינטרנט עם GitHub Pages
1. ב-GitHub נכנסים ל-**Settings → Pages**.
2. בוחרים **Branch: main** ו-**Folder: / (root)**, ולוחצים **Save**.
3. אחרי כדקה המערכת תהיה זמינה בכתובת `https://yigaldf.github.io/aido-customer-services/`

### צפייה מהטלפון
פותחים את הקישור של GitHub Pages מהטלפון. הממשק מתאים את עצמו למסך: בטלפון יש תפריט ניווט בתחתית המסך, ובמחשב יש תפריט צד.
