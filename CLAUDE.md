# Project rules (standing instructions from the owner)

Project: **Neon Peach** — customer-service dashboard demo for a pastel-themed youth bar. Docs are in Hebrew.

For EVERY request / change, without waiting to be asked:
1. **SPEC.md** — update whenever any setting, feature, design or tech decision changes (bump the version line).
2. **README.md** — client-facing explanation (what the system is, tech, how it works, run instructions). Keep in sync with every change.
3. **WORKLOG.md** — add a new row at the top for every request received and every git change: date/time, the request, what was done, files, commit hash.
4. **Git** — commit and push automatically after each change to the working branch. Do not wait for approval.

User preferences: rephrase the user's question in English, answer in the language asked (Hebrew → Hebrew).
